# OPF27 Wireframe Builder (Penpot plugin)

Builds lo-fi wireframes for the Otaku Pop Fes 2027 website redesign as native Penpot layers.

Install in Penpot: Ctrl+Alt+P → paste `https://bmcmbuenviaje.github.io/opf27-penpot-plugin/manifest.json` → Install → open the plugin.
It builds on the current page: Sitemap, Home — Desktop 1440, Home — Mobile 375.

Local dev: `node serve.mjs` serves the files at http://localhost:4400 with CORS.
